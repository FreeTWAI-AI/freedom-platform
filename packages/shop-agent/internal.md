# 我有東西要賣：請幫我做一間內部商店

這間商店不對外公開。你幫我整理我授權提供的商品資料，做出可登入的商品／接單／收款後台，再把商品目錄交回自由工坊，讓工坊會員挑選。這是我自己的商店；我也能另外建立公開商店販售自己的商品。

## 請完成

1. 從我指定的資料整理商品清單、圖片、規格、每件供貨價、可供數量、**每件**運費、出貨和退換貨約定。不確定的資料問我；數量未知時先填 0，確認後再以新成果建立可售版本。
2. 產生內部商店網站。所有商品、訂單、成本收款入口與收件資料都要驗證登入及授權，不能靠隱藏網址、robots.txt 或 noindex 代替存取限制。
3. 教我申請自己的金流並完成後台串接。我的金流收的是公開商店支付的商品成本，不是買家的零售款。
4. 接上工坊 API，輪詢我的轉單。公開店選用商品後，提醒我本人到工坊接受那一版實際售價；你與商店金鑰都不能代為接受。只有買家付款回報後才看得到轉單；為每筆未付成本的 transfer 生成受保護的付款入口，回傳 payment-link。相同轉單不得重複建單／重複收款。
5. 金流通知核對通過才回報成本 paid。收到成本款、且買家款未退款後，才交付出貨人。提供「回工坊登記出貨」的入口。物流由我處理，別替工坊串接物流業者。
6. 依下列範例生成真實 freedom-shop.json。這些是假資料，不可直接替我發布；stock=0 的商品只供整理，不能接單。
