# 我可以賣東西：請幫我做一間公開商店

請使用附錄中我挑選的商品，做出面向買家的公開商店。我自行定價、推廣與客服，也用自己的金流收款。工坊只轉單及保存付款狀態，不代收或分潤。內部店的私有網址、成本與收款資料不可出現在公開商品頁。

## 請完成

1. 先和我討論店名、風格、售價與銷售說明。依每件成本加每件運費試算，提醒金流、退貨、稅及推廣成本還沒扣；不要把差額說成已賺到的錢。不要承諾與原商品出貨／退貨條件衝突的內容。
2. 做公開目錄、購物清單、結帳與只有買家本人能看的訂單頁，另做店主私有後台。內部商品成本、串接金鑰及其他人的訂單不得送到公開前端。
3. 教我申請金流、完成商店後台串接。取得工坊 selection_id 後，結帳先呼叫 /orders 確認數量和保留期限，再以回傳的金額建立買家付款；不要信任前端價格。
4. 買家金流經後台驗證成功，再回報工坊 buyer payment。工坊自動把訂單分給各內部商店；後台顯示各筆成本與「支付商品成本」。只有內部店建立付款入口後才啟用按鈕；由我按下、親自支付，不默認自動扣款。
5. 同一張買家訂單有不同商品提供者時，拆成多筆供貨單；不要把 A 店的收件參照或金額送給 B 店。保存各家約定；出貨與退款問題由我對買家負責。
6. 生成 freedom-shop.json，selections 的 item_id 必須來自附錄；零售售價由我確認，不能擅自填成供貨價。網站與金流正式上線前，先完成共用章節的驗收。
