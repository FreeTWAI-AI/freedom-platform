## 規格層面已定、不需再問的事

以下是本目錄依計畫已定案方向做的設計選擇；若有更好的實作可以改，但不需要 Ted 逐項批准：

- 新交易用新的 order profile `hosted_checkout`，v1 預留不變（EC-SPEC-03 §3）。
- 庫存只有一份實體量 N；`reserved` 計數＝短期預留 H＋已付款未出貨配置 A，所以既有 `stock − reserved` 的讀者（含 `supplier-console/reads.ts`）不必改（EC-SPEC-03 §2）。
- 同一張訂單的 30 分鐘預留到期後不再重新預留；重新付款是從同一份 checkout 建立新訂單（EC-SPEC-03 §4）。
- 晚到的付款先記錄真實收款，再一次性重新配置全部行項；不足時進 `paid_unallocatable` 例外與退款待辦（EC-SPEC-03 §5）。
- 付款確認只來自驗證過的 server 通知或查詢；瀏覽器返回頁只觸發查詢（EC-SPEC-04 §4）。
