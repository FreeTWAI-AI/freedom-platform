## Repeat the check

`npm run check:skill-book-upstreams` reads the latest default-branch commit of each original `upstream_url`, prints a Markdown report, and exits nonzero on drift or an API error. It does not open a pull request, write to GitHub, or deploy.

GitHub Actions workflow `.github/workflows/skill-book-upstreams.yml` runs that command on a weekly schedule and on `workflow_dispatch`. It has `contents: read`, passes the job token only as `GITHUB_TOKEN` so the script can stay under the anonymous rate limit, and appends the report to the job summary. A red run means drift or an API error. It does not open a pull request or deploy.

Before changing a pin, review the compare diff, check the guide’s reading and evidence paths at the new commit, update claims the diff affects, and run `npx tsx --test tests/runtime/skill-book-upstreams.test.ts`. The runtime test uses a fake fetcher and does not call GitHub.
