# 會員體驗、活動與 Game Console 更新

日期：2026-09-27。對應 [PR #17](https://github.com/FreeTWAI-AI/freedom-platform/pull/17)。

## 會員可見更新

- 預設介面改為「自由工坊－明亮」，另可在個人檔案切換「自由工坊－夜航」及「自由工坊－敘生」。桌機與手機的頁面工具、通知與底部訊息控制台一併配色調整。
- 新會員完成定位前可先瀏覽受限預覽；完成定位後，再依權限使用會員資料、工作及聊天室。
- 登入會員可提交公開活動，由平台管理員或主辦公會現任會長審核後開放報名。提交與審核會產生站內公告及通知。
- 全站 Game Console 提供世界頻道、系統動態與會員對話；頁面右上角可快速提出想法、查看說明及參與編修。手機可從訊息抽屜進入世界聊天。
- 開發啟用、頁面指引、Agent 文字版、SKILL.md 與 Fork／PR 連結集中在「參與編修」，減少各頁重複內容。
