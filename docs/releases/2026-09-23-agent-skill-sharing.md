# 技能分享與 Agent 投稿 · 0.12.0

每本技能書可在分享前擲骰子換介紹，並用功能示意圖呈現用途。會員也可複製一段私人指令給 Agent，讓它讀取專案、撰寫介紹與 100 則分享短文，再上傳到本人草稿供預覽送出。

## 操作

- 技能書架 → 分享技能 → 換一句 → 分享／複製介紹與連結。抽選只改同一本書的介紹；分享連結的 `intro` 保存該則文案，主網址維持不變。
- 技能書架 → 上傳技能 → 產生私人上傳指令 → 貼給自己選擇的 Agent。60 分鐘一次性授權只限那份草稿；登入 Cookie 不交給 Agent。
- Agent 完成後 → 重新整理草稿 → 預覽 → 送出技能。介面明示介紹、示意圖與分享短文將公開在網路。公開頁可直接閱讀用途、來源、協作 Issues／PR 與 SKILL.md。
- 長期使用可下載 `freedom-skill-client.tgz`，建立最長 90 天的投稿金鑰；本人可撤銷。CLI 在私人設定檔保存憑證，僅可建立／上傳本人草稿，不具公開、管理會員、操作 GitHub 或付款權限。

## 內容與畫面

25 本既有技能書各有 100 則預寫介紹，共 2,500 則；依收錄版本的用途、功能與限制撰寫，不把手冊說成自動服務。100 則文案會檢查長度與唯一性；投稿內容仍需本人檢查，這不是自動的品質認證。

25 張圖為 built-in imagegen 逐張生成，沿用原始品牌錨點。提示詞、尺寸與檔案雜湊見 [示意圖清單](../design/skill-illustration-manifest.json)，資產保存於 `apps/portal-web/public/brand/skill-illustrations/`。書架保持小書封；介紹頁與 Open Graph 改用 1200×630 流程示意圖。社群平台快取的舊縮圖可能需要重新抓取。

## 授權與資料

詳見 [投稿協定](../../packages/skill-upload-client/protocol.md) 與 [實作說明](../development/agent-skill-upload.md)。一次性授權、長期金鑰只保存雜湊；不寫入 command receipts、公開頁、網址或瀏覽器永久儲存。相同上傳重送只回確認，不建立第二份；變更內容、過期或撤銷後會拒絕。圖片可省略，接受有大小限制的靜態 PNG／JPEG／WebP，重新編碼並移除中繼資料。

公開送出與 GitHub 來源匯入共用一筆交易，固定收錄 commit／授權；已登錄過的本人 Repo 可沿用，既有作品介紹不會被覆寫。社群投稿是自行聲明的來源關係，不授予官方標章、GitHub 寫入或自動 Fork 權限。未公開草稿可撤銷；目前公開後的編修與下架介面尚未提供。

程式由實際 Claude CLI `claude-opus-5-5` 分工撰寫，Codex 整合、審查與驗證。驗證結果以本版 GitHub Actions 和部署紀錄的 exact commit 為準，不以此文件推定尚未完成的部署。
