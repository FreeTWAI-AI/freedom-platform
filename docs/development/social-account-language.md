# 帳號入口與基本導覽的語言

會員可在註冊前選擇繁體中文、English、日本語、한국어 或 Español。預設跟隨瀏覽器的第一個支援語言；沒有支援的語言時使用英文。語言是選用設定，不增加註冊步驟或必填欄位。

## 行為與涵蓋範圍

- 登入、建立帳號、忘記密碼／設定新密碼的表單、處理中提示、驗證與可操作錯誤訊息使用所選語言。電子郵件、12–128 字元的新密碼、選填暱稱、CSRF、速率限制及既有帳號／恢復權限保持原有規則。
- 公開角色入口、免費資源入口、第一個歡迎畫面、快速加入公會的控制項、基本會員導覽、設定與登出提供五種語言。切換語言保留目前的表單、目的地、模式及正在執行的操作。
- 使用者明確選擇時，僅把語言代碼存在這台裝置的 `freedom-interface-language-v1`。回到「跟隨瀏覽器」會移除覆寫；儲存失敗時仍可在當次頁面切換。其他分頁的設定變更與瀏覽器 `languagechange` 事件會同步。沒有會員資料庫語言欄位或跨裝置同步。
- HTML `lang` 隨介面更新。選單使用各語言的原文名稱；手機 320／390px 保留 44px 語言控制與提交按鈕。語言選擇在登入畫面與會員設定均可找到。

公會名稱、題目、技能書、作品、貼文與訊息保留原文。完整定位測驗、部分會員功能、技能書預覽內容與頁面工具尚未全部翻譯；帳號頁明示目前涵蓋範圍。本次不宣稱整個平台已完整多語化，也不把會員內容交給翻譯供應商。

## 採用的入口方式

Facebook 的註冊入口提供語言連結；Discord 可在使用者設定切換 Language。自由工坊採「瀏覽器預設＋註冊前可選＋設定可再改」，降低加入時的操作量。參考：[Facebook 註冊入口](https://www.facebook.com/r.php?locale=en_US)、[Discord 語言設定](https://support.discord.com/hc/en-us/articles/216406447-How-can-I-change-Discord-s-Language)。

## 驗證

`tests/e2e/account-language.spec.ts` 使用隔離 PostgreSQL 與 Chromium，對五個瀏覽器語言各自驗證真實錯誤登入、建立帳號、加入公會及語言設定。另覆蓋重載、覆寫優先順序、輸入與目的地保留、登入中切換且只發出一筆請求、儲存不可用、320／390px 和五種重設表單的本機密碼不一致驗證。這些不代替真人手機、母語校稿或正式電子郵件寄送驗收。

`auth-messages.ts` 僅將原 API error 的 code／status 轉成介面文字；未知的註冊衝突維持中性描述，不因此公開帳號是否存在。既有密碼恢復機制仍由其原模組維護。
