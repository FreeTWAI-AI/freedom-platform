## 路徑 A：登入到看見成果

`登入 → 閱讀真實問題／參與條款 → 自願認領 → 提交 → 補件或驗收 → 看見成果 → 自願回報實益`

本機程式已支援成果紀錄；當事人 benefit observation、跨 Work／Coaching 容量與真人持續意願仍屬 FW-13～FW-15 後續工作。已接受成果不能直接換算收益、會員價值或實際重用。

## 路徑 B：作品曝光到可核實的實收

`本人同意分享 → 自願宣傳／接觸 → 有效商機 → 明示合作條款 → 雙方同意 → 交付／驗收 → 收款回報 → 外部證據核實`

本機工作台已跑通「社群作品 → 商機 → 合作 → 交付 → 收款回報／對方確認」。目前沒有外部行銷發布、真實銀行核對、合約簽章或付款執行。不能把示範帳號的紀錄算作社群成交；`counterparty_confirmed` 也不是 provider-verified。
