# 自由工坊會員入口與公會技能書

2026-09-23 的產品指示優先於先前「定位可略過」的 preview 規則。新註冊會員走：Email／密碼／暱稱 → 封閉式定位 → 公會建議 → 本人確認加入與主力公會 → 領技能書 → 開放平台。既有 staging 示範帳保留相容性；公開資料庫不載入示範帳或測試商品。

## 會員體驗

定位有六題偏好與六題實務情境。規則、題號與 hash 固定，伺服器評分；12 個既有公會都能成為首選。會員可保存進度、重新登入續填，也可在結果頁改選其他公會。題目參考 ai-online 的多軸探索形式，但為本平台重新撰寫，不複製其私人原始碼、歷史答卷或既有題目；不宣稱與舊評量結果相同。

定位稱號來自本人選定的主力公會。基本能力為自行勾選的技術與方法；裝備為自行填報持有的工具／訂閱，不收集 API key、帳密或帳單。技能書為有來源的 Repo，加入公會後立即出現在書架，取得不代表已安裝或已執行。

公會可加入多個，主力只有一個；離開主力前要先更換。公會長未任命就顯示待任命，Repo 作者不會因此取得 officer 權限。成立申請會保存職業、名稱與理由，仍需後续營運處理。職業與有意成立公會的回答保存於私人定位資料。

小隊暫依大計畫採「專案小隊」與「共同目標互助小隊」兩種，待 Ted 補充最後定義。加入要本人申請並由發起人接受；不代為加入、不以三人湊齊作為普通互助開工門檻。

## 聯絡方式與身分

Email／密碼／暱稱必填；Discord、GitHub、LINE 可以略過。登入 email 與可分享的聯絡 email 分開；所有聯絡欄位預設不公開。每個欄位選平台公開、不公開、平台好友、小隊夥伴或公會夥伴，後端依有效關係投影；待接受好友和待加入小隊沒有資料權限。

「平台公開」目前指已登入的同社群會員，沒有匿名人員名錄。原始答案、職業、成立意願及密碼材料不進公開名片。重新定位草稿不覆蓋最後一次已確認的公開能力。

Email／社群 handle 均未驗證，不能據此宣稱擁有對應 GitHub Repo 或其他帳戶。本版尚無寄信驗證、忘記密碼流程或 provider OAuth；不提供以未驗證 Email／slug 重設帳號的捷徑。

## 技能書與 fork

Hao 與 Ted 指定的 11 個公開 Repo 已在 FreeTWAI-AI 保留來源 fork，保留上游授權；不因 fork 啟動上游 Actions、安裝程序或第三方發文。沒有可辨認授權的專案標示 NOASSERTION。另建立五份公會入門技能書，以及供應端客戶端 Repo。

供應端先使用平台網站刊登商品。商店模板與供應端客戶端預設連線到 freetwai.com，經本人在網站批准取得七天、可撤銷的讀取憑證。商店只讀取核准店家與商品目錄；供應端只讀本人商品／供貨請求。修改資料仍在平台網站，沒有公開結帳或支付執行。詳見 [讀取連線協定](client-read-connections.md)。

作者可以保留自己的 public Repo，平台 fork 作技能書並保留來源。作品介紹頁可用作者 GitHub Pages 或自有網域；沒有介紹頁的作品仍顯示來源 Repo，不假造 Pages 網址或啟用自動發布。下一輪可用 freedom-project-page 補齊介紹頁。

## 社群品牌與資料

採用 Ted 提供的自由工坊視覺素材，黑底、螢光綠與電藍。LINE／Discord 連結移除 Facebook 轉址與追蹤參數。LINE 5,000＋1,500、Discord 10,000 標示為 2026-09-23 主辦方提供的概況，非即時、非去重統計；上游開放數據仍保留自身日期與來源。
