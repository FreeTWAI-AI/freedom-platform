# 會員 Game Console

登入後的會員頁（含定位流程）共用底部 44px 訊息列。點擊或按 `~` 展開；展開面板約占桌面視窗高度的 35%，可按 Esc 收合。右上角可開獨立視窗，同一登入工作階段透過 `BroadcastChannel` 同步事件。

會員首頁的「最新動態」直接使用同一份控制台事件，列出最近十筆；點選訊息或頻道會開啟全域控制台對應頻道。切換頁面不會重建控制台。

| 頻道 | 目前來源 |
| --- | --- |
| System / Guide | 導覽、頁面和 API 錯誤、網路狀態、會員通知 |
| AI Trace | 共創功能實際產生的 Agent 工作說明；不顯示隱藏推理 |
| Social Chat | 未讀私訊、公會與小隊訊息，以及已確認的傳送結果 |
| World Broadcast | 目前公會的已發布公告、最近的公開技能書與社群共創任務 |

訊息內容由既有會員 API 讀取；私人訊息只會在具備目前會員資格時取得。發送、已讀與草稿仍由「我的訊息」原頁面處理。控制台每 30 秒刷新聊天和通知；公告、技能書與任務每約兩分鐘刷新，視窗重新取得焦點時也刷新。這是輪詢，不是伺服器推送。

控制台只保留本次頁面工作階段最近 200 筆事件，不寫入瀏覽器儲存空間或資料庫。獨立視窗在開啟前確認會員登入，主視窗登出或 Access 失效時立即清空；重新取得焦點時也會重新確認登入。Console 事件是閱讀摘要，不取代原訊息、公告與技能書頁面的權威紀錄。AI 工作說明在控制台最多顯示前 8,000 字，完整內容仍在原功能頁面；含一次性憑證的私人 Agent 指令不複製到控制台。
