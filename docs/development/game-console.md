# 會員 Game Console

登入後的會員頁（含定位流程）共用底部 44px 訊息列。點擊或按 `~` 展開；動態面板沿用原高度，聊天展開到桌面最多 78dvh／760px、手機 85dvh，可按 Esc 收合。右上角可開獨立視窗，同一登入工作階段透過 `BroadcastChannel` 同步操作事件與頻道顯示設定。聊天正文由各視窗依所選對話讀取，獨立視窗在原主頁關閉後仍可使用。

會員首頁不再重複列出控制台訊息；底部訊息列保持常駐，切換頁面不會重建控制台。

| 頻道 | 目前來源 |
| --- | --- |
| 總頻道 | 本人可見的系統公告、導覽、AI 工作說明與操作動態 |
| 世界聊天 | 開啟此分頁後，讀取世界頻道歷史與新訊息 |
| 公會聊天 | 先選一個本人已加入的公會，只顯示該頻道的對話 |
| 小隊聊天 | 先選一個本人已加入的小隊，只顯示該頻道的對話 |
| 私人聊天 | 先選一位對象，只顯示雙方的對話 |
| 系統導覽 | 頁面導覽、下一步、鍵盤提示與歡迎說明 |
| 系統公告 | 連線狀態、技能書發布、共創任務、驗收、活動公告、通知，以及 GitHub 的 Issue、PR、審查、設計認領與版本發布 |
| AI 指令 | 共創功能實際產生的 Agent 工作說明；不顯示隱藏推理 |

各頻道有不同文字與邊線顏色；錯誤和警告以紅色、橘色優先標示，公告與 AI prompt 另有背景提示。文字上也保留頻道名稱與來源，避免只能靠顏色辨認。

聊天共用「我的訊息」的頻道、私訊元件與既有會員 API。總頻道不預先讀取全部公會、小隊與私訊歷史，也不顯示聊天正文。切換對話保留本次開頁期間的草稿；Enter 送出、Shift+Enter 換行，中文輸入法組字時不送出。送出結果不確定時，以同一冪等鍵重試。可載入較早訊息、手動標為已讀；閱讀舊訊息時保留捲動位置並提供回到最新的按鈕。

可見且開啟的聊天分頁每 8 秒更新所選對話；公會、小隊和世界使用 `after_sequence` 取得增量，失敗時最多延長到 60 秒後重試。私訊更新合併最近訊息與已載入歷史。公告、通知、技能書、共創任務與 GitHub 事件保持 30 秒讀取；GitHub 事件來自 cron 寫入的 `github_repository_events`，不直接輪詢 GitHub。重新取得焦點時核對登入、資格與最新資料。這是輪詢，不是伺服器推送。會員在線狀態、活動分享碼與活動海報或影片不會變成控制台訊息。

控制台只保留本次頁面工作階段最近 200 筆事件，不寫入瀏覽器儲存空間或資料庫。獨立視窗在開啟前確認會員登入，主視窗登出或 Access 失效時立即清空；重新取得焦點時也會重新確認登入。Console 事件是閱讀摘要，不取代原訊息、公告與技能書頁面的權威紀錄。AI 工作說明在控制台最多顯示前 8,000 字，完整內容仍在原功能頁面；含一次性憑證的私人 Agent 指令不複製到控制台。

最新會員入口、手機截圖、驗證紀錄與 staging 驗收方式見 [簡約會員體驗](calm-member-experience.md)。
