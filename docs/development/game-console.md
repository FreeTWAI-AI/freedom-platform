# 會員 Game Console

登入後的會員頁（含定位流程）共用底部 44px 訊息列。點擊或按 `~` 展開；展開面板約占桌面視窗高度的 35%，可按 Esc 收合。右上角可開獨立視窗，同一登入工作階段透過 `BroadcastChannel` 同步事件。獨立視窗也自行輪詢，原主頁關閉後仍會接收新訊息。

會員首頁不再重複列出控制台訊息；底部訊息列保持常駐，切換頁面不會重建控制台。

| 頻道 | 目前來源 |
| --- | --- |
| 總頻道 | 會員看得到的所有已開啟頻道 |
| 世界聊天 | 會員自己送出的世界訊息 |
| 公會聊天 | 公會頻道訊息，以及公會幹部發布的公會公告 |
| 小隊聊天 | 小隊頻道訊息 |
| 私人聊天 | 私人訊息 |
| 系統導覽 | 頁面導覽、下一步、鍵盤提示與歡迎說明 |
| 系統公告 | 連線狀態、技能書發布、共創任務、驗收、活動公告、通知，以及 GitHub 的 Issue、PR、審查、設計認領與版本發布 |
| AI 指令 | 共創功能實際產生的 Agent 工作說明；不顯示隱藏推理 |

各頻道有不同文字與邊線顏色；錯誤和警告以紅色、橘色優先標示，公告與 AI prompt 另有背景提示。文字上也保留頻道名稱與來源，避免只能靠顏色辨認。

訊息內容由既有會員 API 讀取；私人訊息只會在具備目前會員資格時取得。總頻道顯示所有已開啟頻道的訊息，輸入區直接發送世界聊天；切到私人、公會或小隊聊天時才選擇對象。各目標保留本次開頁期間的草稿；送出結果不確定時，以同一冪等鍵重試。已讀與完整歷史仍可在「我的訊息」查看。可見的控制台視窗每 30 秒重讀聊天、通知、公告、技能書、共創任務與 GitHub 事件；世界聊天每 10 秒另讀一次。GitHub 事件來自 cron 寫入的 `github_repository_events`，這次輪詢不再呼叫 GitHub。視窗重新取得焦點時也刷新。這是輪詢，不是伺服器推送。會員在線狀態、活動分享碼與活動海報或影片不會變成控制台訊息。

控制台只保留本次頁面工作階段最近 200 筆事件，不寫入瀏覽器儲存空間或資料庫。獨立視窗在開啟前確認會員登入，主視窗登出或 Access 失效時立即清空；重新取得焦點時也會重新確認登入。Console 事件是閱讀摘要，不取代原訊息、公告與技能書頁面的權威紀錄。AI 工作說明在控制台最多顯示前 8,000 字，完整內容仍在原功能頁面；含一次性憑證的私人 Agent 指令不複製到控制台。
