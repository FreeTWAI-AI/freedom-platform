# 簡約會員體驗

Hao0321 在 [PR #68](https://github.com/FreeTWAI-AI/freedom-platform/pull/68) 後續提交（`05e6f71`、`cf82280`、`0afdc78`）處理註冊、找功能、加入公會之後與聊天室延遲的問題。這些修改連同 [新人入口與會員交流](member-connections.md) 一起整合。

## 會員可直接使用的流程

| 入口 | 行為 |
| --- | --- |
| 訪客 | 登入頁說明學習、夥伴與合作三項用途；展開「先看免費資源，不用註冊」才讀取三份真實社群技能書，可免費預覽。 |
| 建立帳號 | 只有 Email、密碼必填。名稱選填，空白時產生 `新夥伴` 加隨機字串，不取用 Email 當公開名稱；密碼仍至少 12 字。 |
| 選擇公會 | 搜尋名稱或按主題篩選，選主要公會、回答該公會 3–4 個小問題即可加入並領書。完整定位與提交活動放在「想先探索其他參與方式？」選填區。 |
| 加入之後 | 首頁只有一個下一步區，依名片狀態給一句建議。已有主要公會時，提供「閱讀第一本技能書」（只在本人確實已領取時；否則「前往技能書架」）、「進入〈主要公會名稱〉聊天室」，以及第三個依工作事實決定的小按鈕：本人有尚未結案的認領時是「回到我的工作」，否則是真實社群任務或作品分享。已加入的公會卡片也能直接開啟該公會聊天室。 |
| 找功能 | 主要入口加入「我的訊息」；導覽的「搜尋功能」同時認得頁名與「聊天室」「電商」等常用詞。 |
| 聊天 | 通知、公會、小隊、私訊與世界各自分頁；選定公會、小隊或對象後才讀取該對話。總頻道只顯示系統公告與操作動態，不混入聊天正文。 |

原有品牌圖、中文字標與三種主題保留。明亮主題沿用 [DESIGN.md](../../DESIGN.md) 的萊姆綠主操作與膠囊按鈕，只減少卡片光暈、取消快訊跑馬動畫，並縮小首頁裝飾圖。Hao 提議的深綠白字主按鈕與藍色選取色沒有採用，因為 DESIGN.md 以原 Logo 與萊姆綠主操作為最高視覺錨點；要換色需另行提案並更新 DESIGN.md。

好友接受／移除完成後，依目前正在看的名單重新讀取，避免快速切換後被舊的邀請列表覆蓋。再次點選同一個「我的好友」範圍也會重新整理。

## 聊天互動與 API

控制台與「我的訊息」使用同一組頻道／私訊元件。草稿只保存在目前開頁的記憶體，按對話分開；Enter 送出、Shift+Enter 換行，中文輸入法組字期間不送出。傳送結果不確定時沿用同一冪等鍵，避免重複訊息。較早訊息、手動已讀、失敗重試、離開公會後撤銷資格與晚到回應的防護保留。

底部控制台選定公會、小隊或私訊對象後收起列表，以「切換公會／小隊／對象」返回選擇。選擇與對話共用同一塊空間，手機上仍可直接操作輸入框與送出按鈕；完整訊息頁保留並排的桌面布局。

可見且開啟的對話每秒檢查一次小型、沒有正文的 `/activity` 回應，有新訊息或未讀變化才讀取訊息。收合控制台、返回對象選擇、切到其他分頁、離線與傳送中會暫停檢查；網路失敗逐次退避，最多 60 秒。私訊的其他對話列表每 8 秒更新。送出後立即顯示「傳送中」，收到伺服器確認後才成為正式訊息；未知結果保留草稿與原冪等鍵。

送出聊天不再觸發整批未讀清單與平台動態重讀；接收到新訊息或標為已讀時仍重新核對真實未讀數。頻道訊息可用 `after_sequence` 增量游標，原本的最近訊息和 offset 分頁保持相容；頻道搜尋由伺服器在分頁前篩選，未讀總數仍是全部可用頻道。路徑與欄位見 [會員設定、待辦與訊息](member-settings-messages.md)。這是 HTTP 輪詢：接收等待約為下一次檢查加網路／API 時間，沒有 WebSocket 推送。

重新取得視窗焦點會核對列表、資格與登入狀態。API 仍是存取權限的判斷來源；首頁與公會卡片的聊天室開啟事件只是導覽，不授予公會權限。聊天正文不複製到 Console 摘要、BroadcastChannel 或瀏覽器永久儲存。

## 30 秒入口目標

`tests/e2e/calm-experience.spec.ts` 使用隔離 PostgreSQL 與合成帳號，以每字 100ms 輸入 Email、密碼，選一個公會並回答小問題，到首頁出現下一步為止，要求少於 30 秒。這是本機合成操作預算，不包含真人閱讀、思考、網路環境或 staging Access 登入；真人完成率仍需在測試站觀察。
