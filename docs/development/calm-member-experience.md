# 簡約會員體驗與 staging 交接

本輪接續 [PR #68](https://github.com/FreeTWAI-AI/freedom-platform/pull/68)，回應 Hao 的註冊、導覽、公會加入後與聊天室問題。程式提交維護者審查；staging 受 Cloudflare Access 保護，使用者外出暫時無法登入，尚未部署或驗收測試站。

## 會員可直接使用的流程

| 入口 | 行為 |
| --- | --- |
| 訪客 | 先看到學習、夥伴與合作三項用途；可免費預覽三份真實社群資源。 |
| 建立帳號 | 只有 Email、密碼必填。名稱選填，空白產生 `新夥伴` 加隨機字串，不取用 Email 當公開名稱；密碼仍至少 12 字。 |
| 選擇公會 | 搜尋名稱或按主題篩選，選主要公會即可加入並領書；原有完整定位放入選填探索區。 |
| 加入之後 | 首頁直接開啟本人主要公會已領的第一本技能書、該公會聊天室，以及真實社群任務；暫無任務時提供作品與需求分享入口。 |
| 找功能 | 六個主要入口加入「我的訊息」；功能搜尋同時認得頁名與「聊天室」「電商」等常用詞。 |
| 聊天 | 通知、公會、小隊、私訊與世界各自分頁；選定公會或對象後才讀取該對話。總頻道顯示系統與合作動態。 |

原有圖片、品牌中文字標與三種主題保留。明亮版採白色表面、中性邊界、深綠主按鈕，縮小裝飾圖並取消快訊跑馬動畫。活動發佈、社群任務、貢獻事實、商品與合作功能沿用既有真實資料；本輪不以示範紀錄宣稱有營收或多人分潤。

## 聊天互動與 API 相容

控制台與「我的訊息」使用同一組頻道／私訊元件。草稿只保存在目前開頁記憶體，按對話分開；Enter 送出、Shift+Enter 換行，中文輸入法組字期間不送出。傳送結果不確定時沿用同一冪等鍵，避免重複訊息。較早訊息、手動已讀、失敗重試、離開公會後撤銷資格與晚到回應的防護保留。

可見且開啟的對話每 8 秒更新；公會、小隊和世界失敗時退避到最多 60 秒。頻道 API 新增可選 `after_sequence` 增量游標；原本最近訊息和 offset 分頁保持相容。頻道搜尋由伺服器在分頁前篩選，未讀總數仍是全部可用頻道。這是 HTTP 輪詢，尚未實作 WebSocket 推送。

重新取得視窗焦點會核對列表、資格與登入狀態。API 仍是存取權限的判斷來源；首頁的聊天室開啟事件只是導覽，不授予公會權限。聊天正文不複製到 Console 摘要、BroadcastChannel 或瀏覽器永久儲存。

## 30 秒入口目標

`tests/e2e/calm-experience.spec.ts` 使用隔離 PostgreSQL 與合成帳號，以每字 100ms 輸入 Email、密碼，選一個公會，到首頁出現第一本技能書為止，要求少於 30 秒。測試輸出附時間與輸入長度；這是本機合成操作預算，不包含真人閱讀、思考、網路環境或 staging Access 登入。真人達成率仍需在測試站觀察。

## 本輪驗證

完整 runtime、瀏覽器回歸、Worker 打包與 source inventory 使用實際輸出記錄。結果於提交前補入本節；先前版本的驗證歷史保留在 [會員交流規格](member-connections.md)。

## Ted 可用的 staging 驗收

1. 使用既有隔離的 staging 資料庫，先套用本 PR 的 migration 058；本輪聊天與名稱選填不再新增 migration。依目前部署流程部署 PR 的確切 commit，核對 health `release_sha` 與該 commit。
2. 使用合成帳號開匿名入口：預覽資源、只填 Email 和密碼、選一個公會。確認首頁可閱讀已領技能書並直接進入公會聊天，定位仍可稍後補做。
3. 以兩個合成帳號測試兩個公會：A 的訊息不混入 B 或總頻道；切換保留各自草稿，按 Enter 送出、Shift+Enter 換行，新訊息自動更新。另確認私訊、小隊、世界聊天與獨立視窗。
4. 驗證功能搜尋、320px／390px 手機寬度與三款外觀；保留原圖完整比例。檢查斷線重試、歷史分頁和離開公會後不能再讀寫。
5. 用真人測量從首次按「建立帳號」到看到可參與的第一步；觀察卡在哪個欄位、等待或說明，再決定後續修改。

需要回退時，回退應用程式並保留 migration 058、會員加入與領書事實。選填名稱與頻道查詢參數是向後相容擴充，不需刪除會員資料。PR 審核、staging 登入與發版由有權限的人依既有流程完成。
