- 同一 GitHub 穩定 user ID 只綁一個工坊會員。migration 034 遇既有重複會整筆失敗，不擅自合併或選擇主人；同時 OAuth／直接資料庫寫入有唯一約束和 SAVEPOINT 防護。衝突只回一般訊息，不洩漏另一會員資料或撤銷其 token。staging／public 遷移前唯讀檢查皆為 0 組重複。遷移從一開始就拿 DDL 所需的鎖，消除與進行中 callback 升鎖互等的死結；有實際 migrate 的回歸案例。[詳情](./github-identity-uniqueness.md)
