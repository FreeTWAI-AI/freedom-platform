# 自由工坊軌道工坊視覺版

此版把原始自由工坊品牌圖的黑底、萊姆綠、電光藍、鉻金屬與軌道延伸為 RPG 介面。Spotify 僅提供深色分層、側欄、封面網格與膠囊控制的結構參考。最高視覺準則見根目錄 [DESIGN.md](../../DESIGN.md)。

登入保留完整原始品牌圖；會員首頁是自己的公會基地。主次公會、科技技能書、真實會員能力與協作任務使用同一套視覺。供貨、零售、開源與行銷仍各有清楚入口。RPG 不增加虛構等級、XP、成就、商品照片或交易事實。

四張原創圖片由內建 GPT imagegen 生成，再做 WebP 格式壓縮（無裁切、無改圖）。完整生成提示詞和輸出路徑見 [rpg-art-manifest.json](rpg-art-manifest.json)：

- `workshop-hub.webp`：會員與公會軌道基地。
- `skill-codex.webp`：科技技能書及其介紹頁。
- `cooperation-forge.webp`：共創、任務、小隊與內容工作台。
- `market-network.webp`：供貨與商店網路。

檔案均位於 `apps/portal-web/public/art/rpg/`；瀏覽器不依賴生成工具的私人路徑。原始品牌圖仍是 `public/brand/freedom-workshop.webp`。圖片只承擔裝飾；所有操作文字、導覽與事實資料由 HTML 呈現。

## 驗證入口

`tests/e2e/workshop-design.spec.ts` 以隔離的示範資料，核對原圖完整比例、320/390px 各模組導覽與頁面寬度、四張本地圖片以及瀏覽器錯誤；並產出桌面與手機截圖供人工檢視。其餘既有登入、定位、隱私、公會、技能書、供貨、共創與管理測試繼續執行。命令與結果由該次發布紀錄提供，不能把本文件當作已跑測試的宣告。

## 定位結果與合作偏好

完成入門定位後，「我的定位」先顯示已發布的稱號、主次公會與主力技能。重新探索由本人主動開啟；尚未完成的重測草稿不能覆蓋既有名片。舊版獨立方向卡保留為收合的「合作偏好（選填）」，用於額外的合作目標、時間與角色，不再以尚未填寫誤稱入門定位未完成。既有內容保留，不替會員生成或自動保存未回答的目標。
