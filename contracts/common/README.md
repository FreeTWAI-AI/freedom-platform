# Common identity references (v1, local foundation)

[v1/identity.ts](v1/identity.ts) is the single authoring source for `PrincipalRef` and `ResourceScopeRef`: Zod validators plus inferred TypeScript types. References contain only an opaque lowercase UUID and kind. They are not credentials, a VerifiedContext, a grant or an authorization decision.

`npm run contracts:common` generates [principal-ref.schema.json](v1/principal-ref.schema.json) and [resource-scope-ref.schema.json](v1/resource-scope-ref.schema.json). `npm run check:common-contracts` checks exact generated bytes without writing. JSON Schema uses Draft 2020-12 and disallows additional properties; [Zod's JSON Schema conversion](https://zod.dev/json-schema) generates it from the same validator. UUID spelling, length and variant are explicit, including rejection of uppercase and trailing newlines.

The wire kinds reserve person/service principals and community/personal/site scopes. Only person/community/personal mappings exist in the current [server package](../../packages/resource-scopes/README.md); the database and member resolver reject service/site activation. Parsing a reserved ref cannot activate an adapter. Scope equality is not resource permission.

The generated schemas are checked by the ordinary repository CI and local runtime fixtures, including a Python JSON Schema validator. This is not TS/Rust conformance, trusted CI enforcement or a published ReleaseSet. No preview v1 bytes, SDK exports, consumer pins or HTTP negotiation have changed. Publishing common contracts and attaching shared cross-language vectors remain subsequent work.
